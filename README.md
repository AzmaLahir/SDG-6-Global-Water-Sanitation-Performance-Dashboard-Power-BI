# SDG 6: Global Water & Sanitation Performance Dashboard

## Overview
An interactive Power BI dashboard evaluating global, regional, and country-level performance toward **UN Sustainable Development Goal 6: Clean Water and Sanitation**. This report tracks key indicators including access to safely managed drinking water, sanitation services, hygiene facilities, and official development assistance (ODA) allocations.

---

## Key Features & DAX Implementation
- **Global & Regional Metrics**: Dynamic KPIs summarizing target coverage percentages, regional disparities, and year-over-year progress.
- **Service Level Breakdown**: Categorized analysis of safely managed vs. basic vs. unimproved water and sanitation services.
- **Data Modeling & Measures**: Custom DAX calculations for weighted regional averages, dynamic rank metrics, and conditional indicator status.
- **Interactive Filtering**: Dynamic Slicers for SDG Regions, Income Groups, and Target Years.

---

## Tools & Technologies
- **Power BI Desktop**: Data modeling, star-schema architecture, and interactive dashboard design.
- **Power Query (M)**: Data transformation, unpivoting yearly indicators, and handling missing values.
- **DAX (Data Analysis Expressions)**: Custom measures for dynamic aggregations and KPI scoring.
